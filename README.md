# Quant-for-babies-extra-2


本仓库围绕量化投资的完整研究流程，系统介绍金融数据工程、量化因子构建、因子有效性检验以及多因子策略与回测。

课程采用理论讲解、交互式 HTML 教程、Python 实操和模拟实验相结合的形式，帮助学习者建立从金融数据处理到策略研究与实证分析的完整知识框架。

所有 HTML 课件均可下载后在浏览器中离线阅读，部分章节提供配套 Python 实验代码、可视化工具和课堂练习。

---

## 四、如何使用本仓库

### 1. 在线学习

进入对应课程文件夹，点击 `index.html` 查看 HTML 课件。

GitHub 文件预览页面主要展示 HTML 源代码。如需正常使用课件中的交互功能，建议下载文件后使用浏览器打开。

### 2. 离线学习

可以下载单讲的 `index.html` 文件，也可以克隆整个仓库：

```bash
git clone https://github.com/ThreshoLdnnis/Quant-for-babies-extra-2.git
```

下载后使用 Chrome、Edge 等现代浏览器打开对应 HTML 文件即可。

### 3. 运行 Python 实操

建议使用 Python 3.11 环境。

进入对应课程文件夹，优先阅读该讲的 `README.md`，根据运行说明安装依赖并执行实验代码。

例如：

```bash
python lab.py
```

不同章节的实操脚本和依赖可能有所不同，请以各讲说明文档为准。

## 五、课程数据与实验说明

为保证课程内容具有可复现性，并避免将教学实验误认为真实投资结果，特别说明：

1. 第一讲及各章节中的模拟图表、虚构股票和模拟账户均用于教学演示。
2. 第三讲使用 8 只虚构股票构建因子实验数据。
3. 第四讲沿用第三讲的模拟数据与固定因子方向开展有效性检验。
4. 第五讲使用确定性模拟账户进行策略回测与交易核算。
5. 模拟结果不代表真实市场表现，不构成投资建议。
6. 第四讲和第五讲明确说明短样本条件下的统计检验与样本外实证局限，不将模拟结果包装为真实市场实证结论。

## 六、学习路线建议

建议按照课程顺序学习，逐步建立完整的量化研究能力：

```text
量化投资基础
      ↓
金融数据工程
      ↓
量化因子构建
      ↓
因子有效性检验
      ↓
多因子策略构建
      ↓
回测与实证研究
```

学习过程中建议结合 HTML 课件、讲者备注和 Python 实操代码，先理解理论，再动手完成实验，最后尝试独立解释实验结果。
